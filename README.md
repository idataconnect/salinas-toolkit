# Salinas Toolkit

Salinas Toolkit is a public domain fork of **Casciian v0.1**, an original work by **Autumn Lamonte** built upon **Jexer 2.0**.

### Purpose
This fork was established to implement essential features and refinements required for the **salinas-ui** project that were not present in the original distribution. While development is primarily driven by the specific needs of `salinas-ui`, these contributions are shared in the hope that they may prove useful for other applications or general use.
